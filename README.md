# flumen-receiver

Récepteur Google Cast (Custom Web Receiver) de FlumenTV, servi par GitHub Pages :
https://xtbmz.github.io/flumen-receiver/ (App ID `F4CFBFAD`).

- `index.html` : charge le SDK CAF v3 et habille le lecteur aux couleurs de FlumenTV.
- `receiver.js` : ES5 (Chromecast 1re génération), force le HLS en segments TS pour les directs IPTV.
